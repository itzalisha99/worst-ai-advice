Entry for [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) on make.fun.

`main.py` writes one line of the worst possible advice an AI could give to
`/output/entry.txt` — confident, tidy, concrete, and exactly the sort of
thing a reader could follow and instantly regret:

> For maximum password security, write all your passwords on a sticky note on your monitor — hackers can't read paper.

Run it with:

```sh
python3 main.py
```

The program checks the line against the bounty gate first (1–140 characters,
a single line, not only whitespace) and refuses to write anything invalid.
